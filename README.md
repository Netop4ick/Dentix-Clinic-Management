
# Dentix Clinic Management

Система предназначена для автоматизации работы стоматологической клиники.
Она обеспечивает запись пациентов, ведение медицинских карт, учет материалов, услуг и оплат.

## Основные возможности

- Запись пациентов на прием.
- Ведение медицинских карт.
- Учет расходных материалов.
- Учет услуг и оплат.
- Учет рабочих часов персонала.
- Формирование отчетов.
